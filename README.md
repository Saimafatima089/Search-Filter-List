# Live Search Filter

- This is a very simple JavaScript project that helps to filter a list of items in real-time as you type inside a search box.
- When you type a letter, it checks the list of fruits below. If the item name matches your text, it stays on the screen. If it does not match, the item hides automatically.

# Features
- Real-time list filtering using input event listener.
- Dynamic hiding and showing of items using display properties.
- Case insensitive search logic that works with both big and small letters.

# Technology Used
- HTML5 for creating the text box and the list elements.
- JavaScript for handling the loop and text matching logic.
